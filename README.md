# Les traiteurs chinois

Carte-hommage des traiteurs chinois de Paris : un plan à l'encre sur papier, avec une photo pour chaque lieu visité.

- Site statique, déployé sur Vercel (aucun build).
- Ajouter une visite : `python3 scripts/add_photo.py front.jpg [secret.jpg]` puis commit/push.
- Voir `CLAUDE.md` pour le fonctionnement complet.
